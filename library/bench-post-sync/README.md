## Anti-pattern callouts (carried from M3-F1)

1. `--attention-backend ROCM_CK_FA` CLI flag is the only working path
   on the sync branch (`VLLM_ATTENTION_BACKEND` env var is silently
   dropped post-upstream-merge). Match M3-F1.
2. CK FA splitkv does NOT support head_dim=256 — Llama-2-7b
   (head_dim=128) is the only model that exercises ROCM_CK_FA cleanly.
3. rocprofv3 + `bench serve` deadlocks on gfx908 — offline
   `bench throughput` is the only working harness.
4. `bench latency` rejects `--max-model-len 32768` on Llama-2-7b —
   `--max-model-len 4096` is mandatory.
